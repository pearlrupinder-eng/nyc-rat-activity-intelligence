Methodology, definitions, and refresh limitations

Data is an embedded snapshot of the repository's data/daily_metrics.csv. The source archive was last verified 13 October 2026. ZIP and borough come from the source fields. Inspections have UNKNOWN borough in the modeled dataset, so borough filtering excludes inspections and inspection-rate cards by design. 311 reports and inspection visits are different units of observation and must not be divided into a complaint-to-inspection response rate. The existing inspection deduplication key requires a future audit against source event semantics.

September 1–21 is not present. October covers only dates through October 11; the selected period may contain missing dates. Counts for all periods are incomplete for the missing September interval. This standalone page is not connected to a private GitHub repo at runtime; new data requires regenerating the embedded snapshot or moving to authenticated hosting and a refresh endpoint.

Data sources: NYC 311 Rat Sighting complaints (erm2-nwe9) & NYC Rodent Inspections (p937-wjvj). Generated from actual stored data. Not a citywide estimate of rat prevalence. Project repository.
